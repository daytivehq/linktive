# linktive

[English](README.md) | **한국어**

가볍고 빠른 셀프호스팅 북마크 · 웹 아카이빙 서비스입니다.

## 주요 기능

- **PC·모바일 최적화 UI**: PC 좌·우 독립 스크롤, 모바일 1줄 상단 바 및 드로어 메뉴, 리스트/카드 보기(PC), 컬렉션 이름 표시, 표시 항목 선택, 드래그 앤 드롭 컬렉션 정리, 다중 선택 일괄 편집
- **강력한 한국어 검색 & 필터**: 중간 글자(`래명세` → `거래명세서`), 초성(`ㄱㄹ`), 1~2글자, 띄어쓰기 무시, 저장 본문 통합 검색(On/Off), 연산자(`tags:`, `-tags:`, `site:`, `in:`, `date:`, `after:`, `before:`, `is:favorite`, `is:broken`, `is:blocked`, `is:archived`, `-is:archived`) 및 **필터** 저장
- **웹 클리핑 & 아카이빙**: 수동/자동 본문 수집(**리더 뷰** · **원본 HTML** · **둘 다** 저장 및 추가 저장), 이미지·CSS 로컬 캐싱(`/data/assets`), 큰 화면 보기, **Markdown+이미지(`.zip`)** · **PDF** 내보내기
- **URL만으로 빠른 저장 & 링크 점검**: `https://` 생략 가능, 제목·설명·파비콘 자동 수집, **링크 점검**(손상된 링크·접근 제한·중복 URL 탐지 및 정리)
- **컬렉션 & 공유**: 계층 폴더(전체 접기/펼치기 지원), 아이콘(기본 + Iconify)·색상 커스텀, 로그인 없는 공개 링크(`/share/...`, 아카이빙 본문은 비공개), 사용자/소속 공유(본문 열람 범위 제어 지원)
- **브라우저 확장 프로그램**: Chrome 웹 스토어 공식 배포, 현재 탭 원클릭 저장 및 주소창 `lk` 즉시 검색 지원
- **데이터 이동 · 통계 · 자동 백업**: JSON·HTML·Raindrop CSV·엑셀용 CSV 내보내기와 Linkwarden·Karakeep 등 가져오기, 소속/서버 사용량 대시보드, 용량 안전장치(기본 `10MB / 30MB`), SQLite 자동 주기 백업(`/data/backups`)
- **계정·보안 · 다국어 & REST API**: 영어(기본)·한국어 UI 지원, TOTP 2FA(OTP), 관리자 콘솔(회원가입 제어·초대 링크·사용자 관리·고아 에셋 정리·자동 백업), Bearer API 키

## 빠른 시작 (Docker)

### 1. `docker-compose.yml` 작성

```yaml
services:
  linktive:
    image: ghcr.io/daytivehq/linktive:latest
    container_name: linktive
    restart: unless-stopped
    ports:
      - "18080:8080"
    volumes:
      - ./data:/data
```

### 2. 실행 및 접속

```bash
docker compose up -d
```

브라우저에서 `http://localhost:18080` 으로 접속하세요.  
**가장 먼저 가입하는 계정이 자동으로 관리자**로 등록됩니다. 외부에 공개하는 새 설치에서는 첫 가입 전에 컨테이너 환경 변수 `LINKTIVE_SETUP_TOKEN`에 임의의 긴 토큰을 설정하세요.

> 소스에서 직접 빌드하려면 저장소를 내려받은 뒤 `docker compose up --build -d`를 실행하면 됩니다.

## 기본 사용 팁

- **키보드 단축키** — `/` 검색창, `Q` 새 사이트 추가, `Delete` 열어 둔·키보드로 포커스한·다중 선택한 북마크의 삭제 확인. 입력 중에는 단축키가 동작하지 않습니다.
- **아카이빙 검색** — `is:archived`는 열람 가능한 완료 보관본이 있는 북마크를, `-is:archived`는 그 외의 북마크를 찾습니다.
- **공간 간 이동** — 북마크 상세 → 편집에서 쓰기 권한이 있는 다른 공간으로 이동할 수 있습니다. 다른 멤버의 비공개 보관본이 있는 북마크에는 삭제·공간 이동 제한이 적용됩니다.
- **우클릭 메뉴**: 북마크·컬렉션·필터·태그 위에서 마우스 오른쪽 버튼을 누르면 항목별 작업 메뉴가 열립니다.
- **아카이빙 본문 바로 열기**: 북마크의 **`아카이빙됨`** 배지를 클릭하면 큰 화면 리더 뷰로 바로 열립니다.
- **계정 메뉴 (우측 상단)**: 공간 전환(공유 소속이 있을 때), **설정**(표시 언어 변경 포함), **확장 프로그램**, **관리자 설정**, **로그아웃**, **GitHub 버전 링크**를 이용할 수 있습니다.
- **초대 및 회원가입 제어**: **관리자 설정**에서 공개 회원가입을 끄고 1회용 초대 링크를 발급할 수 있습니다.
- **REST API**: **설정 → API 키**에서 토큰을 발급할 수 있으며, 자세한 사용법은 [API.ko.md](API.ko.md) 또는 웹 내 **REST API 활용 매뉴얼**(`/api-docs`)에서 확인할 수 있습니다.

- **Chrome 웹 스토어**: [linktive 설치 페이지](https://chromewebstore.google.com/detail/linktive/opalenmkjhflejpemlkbliiadchgjhje)
- **초기 연결**: 확장 프로그램 설정에서 linktive **서버 주소**와 **API 키**(`설정 → API 키`)를 입력하세요.

## 내부망 링크 수집

내부망 주소도 북마크로 저장할 수 있습니다. 서버가 내부 사이트의 제목·본문·이미지를 가져오거나 링크 상태를 점검해야 하면 Compose의 `.env`에 `LINKTIVE_ALLOW_PRIVATE_NETWORKS=true`를 지정하세요. 기본값은 `false`입니다. 허용하면 공유 사용자가 요청한 페이지도 서버의 내부망 접근 권한을 사용합니다.

## 역방향 프록시

소스의 Compose 구성을 사용할 때 호스트의 Caddy 등에서만 접속한다면 `.env`에서 `LINKTIVE_BIND_IP=127.0.0.1`로 지정하세요. 프록시가 실제 접속 주소를 `X-Forwarded-For`에 추가하는 경우, 앱에서 보는 프록시 주소를 `LINKTIVE_TRUSTED_PROXY_IPS`에 쉼표로 구분해 지정할 수 있습니다. 이미지로 직접 실행하는 경우에도 이 주소 목록과 초기 설정 토큰을 컨테이너 환경 변수로 전달할 수 있습니다.

## 백업 및 저장 공간

- **영구 데이터 볼륨(`./data`)**: SQLite DB, `/data/assets`(아카이빙 이미지·CSS), `/data/backups`(자동 백업 스냅샷)가 모두 저장됩니다.
- **자동 백업** — **관리자 설정 → 자동 백업**에서 **DB만**(`.db`) 또는 **전체 백업**(`.zip`, DB와 보관 이미지·CSS)을 선택하세요. 자동 백업과 지금 백업에 같은 범위가 적용됩니다. 보관 개수는 두 형식을 합산합니다.
- **용량 관리 & 수동 내보내기**: 웹 UI의 **설정 → 통계·사용량** 및 **가져오기·내보내기**, **관리자 설정**에서 사용량 확인과 고아 에셋 정리, 북마크 내보내기와 SQLite 스냅샷 다운로드를 할 수 있습니다.

복원 검증은 전체 백업 ZIP을 새 데이터 디렉터리에 풀고 별도 Linktive 컨테이너에 연결해 진행하세요. ZIP 최상위에 `linktive.db`와 `assets/`가 있습니다. 별도 DB 경로를 설정한 경우에는 그 경로에 DB 파일을 배치합니다. 운영 복구 전에 로그인, 보관 본문과 이미지가 열리는지 확인하세요. 디스크 장애에 대비해 중요한 백업은 다른 저장소에도 보관하세요.
