# linktive 다음 개선 작업

## 1. 계정과 운영 보호

- **2단계 인증 변경 보호** — 등록·재설정 전에 현재 비밀번호를 확인합니다. 이미 2단계 인증을 켠 계정은 기존 OTP도 확인하고, 새 OTP 검증이 끝날 때 기존 설정을 교체합니다.
- **접속 경로와 로그인 제한** — 프록시만 사용하는 설치에서는 앱 포트를 루프백에 바인딩합니다. 지정한 프록시에서 전달한 실제 접속 IP만 신뢰하고, 계정별 제한도 유지합니다. 새 설치의 최초 관리자 등록은 일회용 설정 토큰으로 보호합니다.
- **백업과 복구** — DB·보관 이미지가 포함된 전체 백업의 접근 권한을 서비스 계정으로 제한합니다. 자동 백업 실패를 관리자 화면에 표시하고, 백업 사본을 별도 컨테이너에 주기적으로 복원해 확인합니다.

## 2. 북마크와 보관 자료 관리

- **공유 공간에서 삭제·이동 안내** — 다른 멤버의 비공개 보관본 때문에 삭제나 공간 간 이동이 제한되면 이유를 표시합니다. 일괄 작업에서는 제한된 항목을 먼저 보여 주고, 가능한 항목만 선택해 다시 실행할 수 있게 합니다.
- **다시 저장할 때 기존 파일 보존** — 다운로드 결과를 리소스 URL별로 추적합니다. 실패한 리소스에 기존 로컬 사본이 있으면 재사용하고, 갱신하지 못한 항목은 화면에 표시합니다.
- **공간 간 이동과 편집 충돌** — 웹 상세 화면에 공간 이동을 추가합니다. 저장 시 북마크의 수정 버전을 비교하고, 다른 사용자가 먼저 저장했으면 최신 내용과 내 변경 내용을 확인할 수 있게 합니다.

## 3. 내보내기와 배포 점검

- **엑셀용 CSV** — 수식으로 해석될 수 있는 제목·메모를 텍스트로 내보내는 옵션을 추가합니다. 원문이 필요한 경우에는 JSON 내보내기를 안내합니다.
- **릴리스 확인** — 운영 데이터 백업 사본으로 기존 본문·이미지 열람을 확인합니다. 로그인, 공유 권한, ‘더 보기’, 확장 저장, PDF 출력은 실제 브라우저에서 점검합니다.
